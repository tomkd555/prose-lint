# Academic register

Wordings that read as spoken Japanese, or as stiffer than they need to be, in a
paper, thesis or report. `scripts/register.py --academic` reads the tables
below and reports every match with the line, the replacement and the reason.
`setup.py` copies this file to `~/.prose-lint/academic.md`; edit that copy, or
point `PROSE_LINT_ACADEMIC_REGISTER` at your own.

The bracket at the end of each `Why` names the sources the row rests on. Their
full titles, URLs and the passages quoted are in `references/academic-japanese.md`.
The rules for writing a row are those of `vocabulary.sample.md`: a boundary guard
on every pattern, a pipe escaped as `\|`, and a hit read as a suspicion. A hit
inside a quotation, a term of art or the field's own usage stays, with that reason.


## 文体と文末

| Pattern | Instead | Why |
| --- | --- | --- |
| (?:です\|ます\|ました\|でした\|ません\|でしょう\|ましょう)(?=[。．！？）)]\|\s*$) | 「である」「する」「した」の常体で書く。 | 論文・レポートは常体で書き、敬体と混ぜない。引用は残す。〔公用文Ⅲ-1、東北大、坂間、垂水〕 |
| (?<=[\p{IsCJKUnifiedIdeographs}\p{IsKatakana}ー々の])(?:だ\|だった)(?=[。．])\|(?<!で)だろう(?=[。．、]) | 「である」「であった」「であろう」と書く。「のだ」は「である」で足りることが多い。 | 「である・であろう・であった」は書き言葉専用の文体で、論理を運ぶ文章に合う。〔公用文Ⅲ-1ウ、垂水、樋口〕 |
| じゃ(?=[なあ]) | 「ではない」「ではないか」「でなければ」と書く。 | 「じゃ」は話し言葉の縮約である。〔金沢大、名桜大、法政大、神戸国際大〕 |
| (?<=[\p{IsCJKUnifiedIdeographs}\p{IsKatakana}ー])なん(?:だ\|です\|じゃ)\|(?<=[るたい])ん(?:だ\|です)(?=[。、．，よねけか]) | 「のである」か、言い切りの「である」「する」で書く。 | 「〜んだ」「〜なんじゃ」は話し言葉の文末である。〔柏野2016、白川〕 |
| (?:ちゃ\|じゃ)(?:う\|っ[たて]\|います\|いまし) | 「てしまう」か、言い切りで書く。 | 「〜ちゃう」「〜じゃった」は話し言葉の縮約である。〔柏野2016〕 |
| [？！] | 「。」で終える。問いは「〜だろうか。」「〜ではないか。」と書く。 | 記号で感情や感嘆を足さず、論理で読み手を納得させる。〔東北大、名桜大、徳島大〕 |

## 接続の言葉

| Pattern | Instead | Why |
| --- | --- | --- |
| (?<=^\|[。．！？]\s*)(?:でも\|だけど\|けど\|けれど(?!も)) | 「しかし」「だが」と書く。 | 文頭の逆接の話し言葉である。コーパスでも最も軟らかい段階に入る。〔東北大、名桜大、法政大、馬場2018、柏野2016〕 |
| (?<=[\p{IsHiragana}\p{IsCJKUnifiedIdeographs}\p{IsKatakana}ー])(?:だけど\|けど\|けれど(?!も)) | 「が」「であるが」と書く。 | 文中の逆接の話し言葉である。〔富山県大、名桜大、法政大〕 |
| (?<=^\|[。．！？]\s*)(?:それで(?!も)\|それから\|それと(?![もと])\|だって\|あと(?=[、，])) | 「そこで」「その結果」「また」「さらに」「なぜなら」と書く。列挙は先に整理して示す。 | 思いついた順に足す会話の接続である。〔馬場2018、金沢大、名桜大、室蘭工大、柏野2016〕 |

## 程度と量の副詞

| ちょっ(?:と\|ぴり) | 「やや」「少し」「若干」と書く。 | 話し言葉の程度副詞である。〔神戸国際大、柏野2016〕 |
| いっぱい\|たくさん | 「多く」「多数」と書く。数が言えるなら数を書く。 | 話し言葉の量の副詞である。〔柏野2016〕 |
| だんだん\|どんどん\|ずっと | 「次第に」「徐々に」「急速に」「一貫して」と書く。 | 話し言葉の副詞である。〔東北大、柏野2016〕 |
| もっと(?!も) | 「さらに」「より」と書く。 | 話し言葉の副詞である。〔東北大、柏野2016〕 |
| だいたい\|(?<![\p{IsCJKUnifiedIdeographs}])大体(?![\p{IsCJKUnifiedIdeographs}])\|かなり | 「およそ」「約」と書き、数値を添える。 | 量をぼかす語である。〔東北大、名大図書館、柏野2016〕 |
| 全然\|ぜんぜん\|多分(?![に野割])\|たぶん\|(?<![\p{IsCJKUnifiedIdeographs}])絶対(?:に)?(?![値的温主])\|(?<![\p{IsCJKUnifiedIdeographs}])全部(?![分品])\|(?<![第\p{IsCJKUnifiedIdeographs}])一番(?![目地手線乗]) | 「まったく」「おそらく」「すべて」「最も」と書く。「絶対」は根拠を示すか削る。 | 漢語でも話し言葉に属する副詞で、和語のほうが書き言葉になる。〔柏野2016（石黒2012を引く）〕 |

| ちゃんと\|しっかり(?:と)? | 「適切に」「正確に」「十分に」と書く。 | 話し言葉の副詞で、何をどうしたのかが伝わらない。〔徳島大、柏野2016〕 |
| あんまり\|わりと\|(?<![\p{IsCJKUnifiedIdeographs}])割と | 「あまり」「比較的」と書く。 | 話し言葉の副詞である。〔柏野2016〕 |

## 指示の言葉と名詞

| Pattern | Instead | Why |
| --- | --- | --- |
| こんな\|そんな\|あんな\|どんな\|こういう\|そういう\|ああいう\|どういう | 「このような」「そのような」「あのような」「どのような」と書く。「そんなに」は「それほど」。 | こそあどの話し言葉の形である。〔大手前、東北大、山下ほか2022、柏野2016〕 |
| [どこそあ]っち | 「どちら」「こちら」「そちら」と書く。 | 話し言葉の形である。〔東北大、柏野2016〕 |
| いろんな\|色んな | 「種々の」「様々な」と書く。何があるかを挙げられるなら挙げる。 | 「色々な」の話し言葉の形である。〔東北大、柏野2016〕 |
| (?<=[\p{IsCJKUnifiedIdeographs}\p{IsKatakana}ー」A-Za-z0-9])(?:とか\|なんか\|なんて) | 「AやBなど」と書く。 | 例示の話し言葉である。〔東北大、徳島大、柏野2016〕 |
| (?<![てで])みたい(?:だ\|な\|に\|で\|です\|である) | 「ようだ」「のような」「のように」と書く。 | 「みたい」は話し言葉である。〔大手前、徳島大〕 |
| (?<![\p{IsCJKUnifiedIdeographs}])(?:私\|僕\|俺\|わたし\|ぼく)(?:は\|が\|の\|たち\|達\|も\|に\|と)\|自分(?:は\|が) | 主語を省くか、「本研究では」「本稿では」「筆者は」と書く。 | 学術的な文章では「私」を出さない。「我々」を使う分野もある。〔立命館IR、名桜大、樋口、垂水、柏野2016〕 |
| (?<=^\|[。．！？]\s*)今回は\|この(?:論文\|レポート\|報告書?)(?:は\|で\|の\|が\|に) | 自分の論文を指すなら「本研究では」「本論文」「本稿」と書く。 | 「今回は」「この論文」は話し言葉的とされる。〔奥村、柏野2016〕 |
| 卒論\|修論\|博論\|スマホ | 「卒業論文」「修士論文」「博士論文」「スマートフォン」と書く。 | 略語は正式名称で書く。初出で略記を断れば使える。〔東北大、ja-engineering-paper〕 |
| のせいで\|おかげ(?:で\|だ) | 「により」「の影響で」と書く。 | 感情や主観的評価を含む言い方である。〔東北大〕 |

## 述語と判断の示し方

| Pattern | Instead | Why |
| --- | --- | --- |
| と(?:は)?(?:思\|おも)(?:う\|い(?!込\|出\|つ)\|っ\|います)\|と感じ(?:る\|た\|ま) | 根拠を添えて「と考えられる」と書く。言い切れるなら「である」。 | 主観の表明で、稚拙な印象を与えかねない。〔金沢大、立教大、大阪大、法政大、酒井・関2020〕 |
| と(?:考え\|思っ\|感じ)た(?=[。．]) | 考察は現在形で「と考える」「と考えられる」と書く。 | タ形の思考動詞は学生のレポートに多く、論文には少ない。〔酒井・関2020、法政大〕 |
| のではないか(?=と(?:考え\|思))\|と考察され | 「と考えられる」「可能性がある」と書く。 | モダリティの重ねがけと、論文に現れない「と考察される」である。〔酒井・関2020〕 |
| (?<=[てで])み(?:た\|る\|ました\|ます)(?=[。．、]) | 「〜を試みた」か、「〜した」と書く。 | 「考えてみた」は試行の話し言葉で、書き手が前に出る。〔金沢大〕 |
| ないと(?:いけ\|だめ\|ダメ)\|な(?:きゃ\|くちゃ) | 「する必要がある」「しなければならない」と書く。 | 話し言葉の義務の言い方である。〔室蘭工大〕 |
| (?<=[\p{IsCJKUnifiedIdeographs}\p{IsHiragana}])ないで(?=[、，\p{IsCJKUnifiedIdeographs}\p{IsKatakana}]) | 「せずに」「〜ずに」と書く。 | 話し言葉の形である。〔柏野2016、山下ほか2022〕 |
| (?:図\|表\|Fig\.?)\s*[0-9０-９][0-9０-９.．\-]*\s*(?:を\|から)見ると | 「図Nに示すように」と書くか、削る。 | 「図を見ると」は文章では要らない。〔室蘭工大〕 |

## 判断が要る言い方

| Pattern | Instead | Why |
| --- | --- | --- |
| (?<=[\p{IsCJKUnifiedIdeographs}\p{IsKatakana}ー\p{IsHiragana}])(?:なので\|だから(?!こそ)) | 「ため」「であるため」と書く。 | 文中の理由の話し言葉である。文中なら認める指針もある。〔金沢大、樋口、法政大、室蘭工大〕 |
| とても(?![^。]{0,15}(?:ない\|ません\|ず)) | 「非常に」「きわめて」と書く。数値で示せるなら数値を書く。 | 書き言葉とする文献もあるが、論文・レポートでは「非常に」「きわめて」を選ぶ。〔大手前、見延、柏野2016〕 |
| 完全に\|(?<![\p{IsCJKUnifiedIdeographs}])必ず(?!しも) | 根拠を示すか削る。「ほとんど」「多くの場合」で足りることが多い。 | 100%の限定になる。実験結果で使うなら根拠が要る。〔室蘭工大、柏野2016（石黒2012を引く）〕 |
| と思われ | 根拠を示して「と考えられる」と書く。言い切れるなら「である」。 | 分野で扱いが分かれる。避ける指針と、主語を立てなければ認める指針がある。〔室蘭工大、森畑、坂間、白川、法政大〕 |
| ことが(?:分か\|わか)(?:る\|った) | 「〜である」と書く。示したものがあるなら「〜が示された」。 | 口語的で動作の主体が不明である。〔室蘭工大〕 |
| することができ\|ことが可能(?:で\|な) | 「できる」と書く。 | 論文調を狙うと増えるが、文を長くするだけである。可能性や能力を言う場合は残す。〔奥村、室蘭工大〕 |
| (?<=[\p{IsCJKUnifiedIdeographs}\p{IsKatakana}ー])を行(?:う\|い\|っ\|わ\|え) | サ変動詞で書く（「補正を行った」→「補正した」）。 | 動詞を名詞にして「行う」を足す冗長な言い方である。〔奥村〕 |
| しかしながら\|ほぼほぼ | 「しかし」「ほぼ」と書く。 | 「しかし」「ほぼ」で足りる。〔奥村〕 |
